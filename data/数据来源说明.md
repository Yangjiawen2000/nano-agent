## 需要补充的5个数据来源

### 来源A：MolPharm 2024 附录数据（最高优先级，可直接下载）

**这是最快获得大量数据的方式：**

1. 打开论文页面：https://pubs.acs.org/doi/10.1021/acs.molpharmaceut.3c00880
2. 点击 "Supporting Information"，下载：
   - `mp3c00880_si_002.xlsx`（19.9 KB）
   - `mp3c00880_si_003.xlsx`（141.7 KB）
3. 这两个文件包含**403个NP数据点**，字段包括：粒径、ζ电位、PDI、载药比、给药途径、脑内AUC/血浆AUC比值

> 注意：该数据集的outcome是AUC脑/血浆比值（非%ID/g），且包含鼻腔给药，与当前IV模型不同。建议筛选`Administration Route = IV`的数据行，约有100-150行可用。

---

### 来源B：PNAS 2015 扩展（Wiley组，同一实验室的后续系统研究）

论文：**"Blood-Brain Barrier Transport of Transferrin Receptor-Targeted Nanoparticles"**
PMC: https://pubmed.ncbi.nlm.nih.gov/36297671/

预期数据：不同TfR抗体密度的金NP，脑内摄取定量
估计可提取：5-8行

---

### 来源C：PAMAM树枝状NP系统研究（已在你的文献库中）

论文：**Sharma et al. 2018** (DOI: 10.1016/j.jconrel.2018.06.003)
文件：在你的文献库中已有

打开论文，找 **Table 1 或 Figure 3**，提取：
- 不同甘露糖密度的PAMAM树枝状NP
- 粒径、ζ电位、各器官分布（含脑）%ID/g
估计可提取：4-6行

---

### 来源D：PLGA-Tf系统综合数据

论文：**Transferrin Adsorption onto PLGA NPs (Pharmaceutical Research 2011)**
链接：https://link.springer.com/article/10.1007/s11095-011-0624-1

论文：**Nose to Brain PLGA-Tf NPs (2023)**（已在文献库XLS中）

提取：不同Tf吸附量 vs. 脑内分布
估计可提取：4-6行

---

### 来源E："Cracking the BBB Code" 综述数据表（已在你的库中）

文件：`04_纳米粒子_BBB_数据/ML_AI_Nanomedicine_WIREs2025.pdf`

找 **Table 4（"Comparative data on NPs crossing the BBB"）**，提取全部13行：
- 脂质类、聚合物类、蛋白类、无机类NP
- 字段：粒径、ζ电位、BBB crossing策略、脑摄取%ID/g
估计可提取：13行

## 数据字段说明

| 字段 | 含义 | 备注 |
|-----|-----|-----|
| paper | 论文简称 | 格式：第一作者_期刊_年份 |
| np_type | NP材质 | gold / PLGA / lipid / porous_silicon / PAMAM |
| size_nm | 流体力学直径 (nm) | DLS测量值 |
| zeta_mv | ζ电位 (mV) | |
| peg | PEG修饰 | yes / no / density% |
| ligand | 靶向配体种类 | transferrin / anti_TfR / none等 |
| ligand_count | 每个NP的配体数 | 或nmol/mg |
| kd_nM | 结合亲和力 (nM) | 可空，Kd=koff/kon |
| brain_metric | 脑内递送指标数值 | |
| metric_type | 指标类型 | pct_bbb_crossing / pct_ID_brain / relative_brain_counts |
| model | 实验模型 | mouse_iv / rat_iv / in_vitro_transwell |
| notes | 备注 | |
